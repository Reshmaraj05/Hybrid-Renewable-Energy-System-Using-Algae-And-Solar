# Components

## Overview

This project combines **Solar Photovoltaic (PV)** and **Micro-Algae Bio-Electrochemical Cell (BECC)** technologies with an **ESP32-based IoT monitoring system** to generate and monitor renewable energy.

---

## Hardware Components

| Component | Specification | Purpose |
|-----------|---------------|---------|
| Solar PV Panel | 3 W | Generates electrical energy from sunlight |
| Micro-Algae Bio-Electrochemical Cell | Copper & Zinc Electrodes | Produces bioelectricity through photosynthetic and electrochemical reactions |
| ESP32 Development Board | Wi-Fi Enabled | Controls the system and hosts the IoT dashboard |
| DC-DC Boost Converter | Step-Up Converter | Amplifies the low voltage generated by the algae cell |
| 5V Step-Up Module | Voltage Booster | Provides sufficient voltage for battery charging |
| Lithium-Ion Battery Pack | 11.1 V (3 Cells) | Stores the generated energy |
| ACS712 Current Sensor | Hall-Effect Sensor | Measures output current |
| Voltage Sensor | Voltage Divider | Measures output voltage |
| L298N Motor Driver | Dual H-Bridge | Controls the cooling fan |
| 12V DC Cooling Fan | Brushless DC Fan | Prevents overheating |
| Breadboard & Connecting Wires | - | Circuit assembly and testing |
